# إعداد مساعد AL-RABUOI

هذه الصفحة ودليل الإعداد يجهزان مكان المساعد داخل تطبيق الربوعي فارماسي. لا يوجد اتصال فعلي بمزود ذكاء اصطناعي حتى الآن.

## الاسم والهوية
- الاسم الظاهر للعملاء: AL-RABUOI
- لا تستخدم اسم ZERO داخل التطبيق أو رسائل العملاء.

## الإعدادات المطلوبة لاحقاً
أضف القيم التالية في متغيرات بيئة الاستضافة أو GitHub Actions Secrets فقط:

- `AL_RABUOI_AI_PROVIDER`: اسم المزود المعتمد (مثلاً openai أو مزود متوافق).
- `AL_RABUOI_AI_API_KEY`: مفتاح API الخاص بالمشروع.
- `AL_RABUOI_AI_BASE_URL`: اختياري، فقط إذا كان المزود يتطلب عنوان API مخصصاً.
- `AL_RABUOI_AI_MODEL`: اسم النموذج بعد اعتماده واختباره.

لا تضع المفاتيح في Git أو ملفات المصدر أو رسائل الدردشة. لا تستخدم مفاتيح شخصية أو مفاتيح حسابات أخرى.

## معلومات نحتاج اعتمادها من مالك المشروع
- مزود الذكاء الاصطناعي والنموذج.
- هل يسمح للمساعد بالبحث في المنتجات والطلبات؟ (الافتراضي: المنتجات المنشورة فقط، والطلبات بعد تسجيل دخول العميل).
- لغة الرد الافتراضية: العربية، مع دعم الإنجليزية.
- بريد/رقم تصعيد الاستفسارات الطبية إلى الصيدلي.
- سياسة الاحتفاظ بالمحادثات ومدة الحذف.

## حدود السلامة
- لا يشخّص المساعد الأمراض ولا يصف علاجاً أو جرعات من تلقاء نفسه.
- لا يوصي بصرف دواء يتطلب وصفة دون تحقق صيدلي.
- لا يعرض بيانات طلب أو حساب عميل آخر.
- لا يخترع منتجاً أو سعراً أو مخزوناً أو حالة دفع.
- لا يدعي أن الدفع أو الحجز أو الإرسال قد تم إلا بعد تأكيد النظام.
